E-Commerce Price Sorting Engine
A clean, efficient implementation of product sorting logic for e-commerce platforms. This project demonstrates how to organize product data based on price in ascending order (Low to High) using optimized algorithms.

📌 Overview
In online shopping, the "Sort by Price" feature is critical for user experience. This repository provides a backend and frontend approach to handling product arrays, ensuring high performance even as the product catalog grows.

⚙️ Algorithms Used
Timsort (Default): Used via built-in methods in Python and JavaScript. It is a hybrid of Merge Sort and Insertion Sort, offering O(nlogn) performance.

Quick Sort: The conceptual foundation for in-place sorting in most large-scale systems.
